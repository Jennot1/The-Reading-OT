# The Reading OT

Therapy training and weekly OT-informed learning for teachers, parents, and schools.

## Deploy on Vercel

This is a buildless, responsive HTML website. Use Framework Preset **Other**, no build command, and Output Directory **dist**. The included vercel.json provides these settings.

Includes the original Reading OT logo, the phrase "therapy can be hard; access doesn't have to be", weekly curriculum previews, role-based demo dashboards, sample pricing, and a state-training link area.

## Current scope

This is an interactive prototype. Accounts, payments, parent invitations, and durable student records are not connected. Only enter fictional demo learner names. Final curriculum, pricing, and the official state training destination require configuration before a real launch.

## Assets

Images are included locally in dist/assets. The logo is supplied by the owner. Classroom and activity photography was generated for this project. WebP assets are optimized from the original artwork.
